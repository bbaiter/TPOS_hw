# Описание работы программы

Консольная программа с именем `homework` предназначена для управления набором запущенных копий веб-приложения на Python `server.py`.

## Функционал программы

### 1. Запуск новой копии веб-сервера

Программа поддерживает запуск новых копий с помощью команды:

```shell
./homework start --name <server_name> --port <server_port>
```

где:
* `<server_name>` — уникальное имя новой копии сервера (состоит исключительно из букв в нижнем регистре длиной от 1 до 32 символов);
* `<server_port>` — порт, на котором запускается новая копия сервера.

Процесс запуска новой копии включает следующие шаги:
1. В текущей папке создается новая папка с именем `<server_name>`.
2. В созданную папку копируется файл веб-приложения `server.py` из директории, откуда запускается сама программа.
3. Копия веб-приложения запускается строго из созданной папки внутри tmux-сессии с именем `homework` в отдельном tmux-окне с именем `<server_name>` посредством команды:
   ```shell
   python server.py --port <server_port>
   ```
4. stdout процесса сервера перенаправляется в файл `out.txt` в созданной папке, который служит результатом работы веб-приложения.

> Примечание: порядок аргументов `--name <server_name>` и `--port <server_port>` может быть произвольным.

### 2. Остановка копии веб-сервера по имени

Для остановки конкретной копии используется команда:

```shell
./homework stop --name <server_name>
```

где `<server_name>` — уникальное имя останавливаемой копии сервера.

При выполнении этой команды программа выполняет следующие действия:
1. Процесс копии веб-сервера останавливается.
2. Содержимое файла `out.txt` останавливаемого сервера переносится в отдельную папку `.backup` (соседнюю по отношению к папке с сервером) и сохраняется под именем:
   ```text
   out_<server_name>_<stop_timestamp>.txt
   ```
   где `<stop_timestamp>` — timestamp в момент остановки копии.
3. Tmux-окно этой копии закрывается.
4. Папка этой копии удаляется.
5. Остальные копии остаются нетронутыми.

> Примечание: timestamp проверяется приблизительно.

### 3. Остановка всех копий веб-сервера

Для остановки всех запущенных копий используется команда:

```shell
./homework stop_all
```

При выполнении этой команды:
1. Все процессы копий останавливаются.
2. Tmux-окна всех копий закрываются.
3. Tmux-сессия `homework` закрывается.
4. Содержимое файлов `out.txt` бэкапится (аналогично пункту 2).
5. Все папки копий удаляются.

### 4. Сбор результатов работы всех копий

В процессе своей работы каждая копия сохраняет результаты в файл `out.txt` в своей директории. Для сбора результатов используется команда:

```shell
./homework collect_all
```

Программа собирает и выводит содержимое файлов `out.txt` всех активных копий, отсортированное по имени копии лексикографически (например: сначала `a`, затем `ab`, затем `b` и т. д.).

Формат вывода:

```text
=== server: a ===
<содержимое a/out.txt>

=== server: ab ===
<содержимое ab/out.txt>

=== server: b ===
<содержимое b/out.txt>

...
```
